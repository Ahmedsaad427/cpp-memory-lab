# C++ Memory Lab
Interactive Stack/Heap simulator for dynamic memory allocation (React + TS + Vite + Tailwind + Framer Motion).

## Windows CMD
```
cd cpp-memory-lab
npm install
npm run dev
```
Open the URL shown (usually http://localhost:5173). Production check: `npm run build`.

Addresses (0x1000, 0x7000…) are simulated and illustrative only.
Supported syntax is listed in the error message shown for unsupported statements.
